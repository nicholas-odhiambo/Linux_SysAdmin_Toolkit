# Linux_SysAdmin_Toolkit
A collection of linux system administartion scripts, automation tools .d documentation.
This reposistory serves as both a toolbox for daily operation and learning portfolio. 

## Repository structure  
-`monitoring/` -> scripts for checking disk, CPU, memeory   services 
`backups/` -> Backup automation scripts
-`user_management/` -> User and Group Management utilities  
-`networking/`-> Network Diagnostic and firewall helpers
-`docs/` -> Documentation and Server setup guides 

## Getting Started 
1. Clone the repo:
   ```bash
   git clone git@github.com:your_username/linux_systemadmin_toolkit.git

2. Make scripts executable
   ```bash
   chmod +x scriptname.sh

3. Run Script
   ```bash
   ./foldername/scriptname.sh
